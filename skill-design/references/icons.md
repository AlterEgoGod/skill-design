# Иконки

Каталог Skill Design: **Lucide** и **Reicon**. Дата проверки документации и пакетов: 8 ноября 2026.

## Выбор

| Инструмент | Назначение | Что включено |
| --- | --- | --- |
| [Lucide](https://lucide.dev/icons/) | Основной контурный набор по умолчанию | Внешнее подключение в примерах; пакет lucide-react или lucide для проекта |
| [Reicon](https://reicon.dev/icons) | Альтернативный основной набор; Outline и Filled | Каталог и подключение reicon / reicon-react, без локального архива |

В демонстрации дизайна предоставляй выбор Lucide или Reicon. При переключении заменяй весь набор через явное сопоставление смысловых имён иконок, а не только подпись в настройках. В готовом продукте используй выбранный набор; настройка для конечного пользователя нужна только по задаче продукта.

## Общие правила

Один основной визуальный набор на проект или согласованную поверхность. Размеры обычно 16 px в строках, 18–20 px в навигации, 24 px для отдельных иллюстративных ролей. Согласуй толщину, оптический размер и поля вокруг рисунка. Не смешивай Outline/Filled случайно: заливка может обозначать выбранное состояние, если это понятно и последовательно.

Кнопка с иконкой имеет доступное имя и удобную область нажатия; декоративная иконка скрыта от accessibility tree. Цвет берётся из роли текста/состояния. Ошибка, статус и действие не объясняются только цветом или движением.

## Reicon

[Документация](https://reicon.dev/docs) · [Vanilla JS](https://reicon.dev/docs/vanilla) · [Исходники](https://github.com/dqev/reicon).

Для обычного JS проверен пакет `reicon`. React использует отдельный `reicon-react`; также существуют адаптеры Vue, Svelte, Angular, Astro и React Native. Их версии/зависимости проверяй отдельно — выбирай подходящий адаптер проекта.

```sh
npm install reicon@1.2.5
```

Проверенный JS API: именованный импорт `Home` из `reicon`; `Home({ size: 20, weight: 'Outline' })` создаёт SVG-элемент в браузере. `weight` принимает `Outline` или `Filled`. Используй реальные экспортируемые имена из текущего пакета, не переименовывай автоматически иконки Lucide в одноимённые Reicon. Для SSR обращайся к серверному API пакета, а не к функции, требующей document.

Репозиторий объявляет MIT и отдельно указывает происхождение части базовых элементов из Solar Icons (480 Design, CC BY 4.0) и Zappicon. Сохраняй copyright, лицензии и upstream credits выбранных ресурсов; не вырезай атрибуцию при переносе графики.

## Lucide и интеграция

React: `npm install lucide-react`, затем `import { Search } from 'lucide-react'`.
Обычный HTML в примерах:

```html
<script src="https://unpkg.com/lucide@0.468.0/dist/umd/lucide.min.js"></script>
<i data-lucide="search" aria-hidden="true"></i>
<script>lucide.createIcons();</script>
```

Версия примеров фиксирована для воспроизводимости, не объявляется последней. Для нового проекта проверь текущую совместимую версию в [документации Lucide](https://lucide.dev/guide/). В скилле нет файлов иконок, runtime-библиотек и архивов. Подключение выполняется в целевом проекте; при CDN браузер получает библиотеку по сети. Пакетный импорт позволяет сборщику включить используемые иконки. Не устанавливай все наборы одновременно.
