# Проверка эффективности

Разделяй три вида доказательств: модульные тесты инструмента; контрольные UI-примеры до/после исправления; независимый эксперимент качества агента без скилла и с ним. Первые два не доказывают третье.

Для сравнения работы агента подготовь четыре одинаковых стартовых проекта: новый дашборд, узкая правка одного контрола, интерактивное сравнение, исправление контраста. Для каждой пары сохрани одинаковые модель, параметры, инструменты, данные и текст задания; меняется только доступ к скиллу. Выполняй в отдельных чистых сессиях, оценивай результаты без указания варианта и по возможности повтори несколько раз.

Метрики: выполнение сценария, внесённые регрессии за пределами задачи, фактические переключения оформления, контраст, клавиатура, адаптивность, ошибки сборки. Сохраняй исходный commit, задания, diff, отчёты и ограничения. Не подменяй запуск без скилла намеренно плохим кодом. Если независимые прогоны не выполнены, помечай их как «не проведены».

Контрольные примеры проверки инструментов можно запускать в CI: отсутствие переполнения/ошибок, намеренное переполнение, неназванная кнопка для axe-core. Ожидаются коды 0, 1, 1 в строгом режиме. Это тест обнаружения проблем, а не оценка того, насколько лучше агент проектирует интерфейсы.
