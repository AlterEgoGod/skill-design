# Skill Design

Переиспользуемый скилл для проектирования интерфейсов: приложений, SaaS, дашбордов и продуктовых лендингов. Объединяет UX/UI-правила, типографику для русского и английского языков, наборы иконок и CSS-переменные дизайн-системы.

## Как работает

Для нового интерфейса скилл предусматривает три направления на одинаковых данных:

| Направление | Характер |
| --- | --- |
| **Точный** | Ясная структура, сдержанная геометрия и компактный рабочий ритм |
| **Мягкий** | Более свободная композиция, плавные формы и лёгкая глубина |
| **Выразительный** | Сильная иерархия, заметный смысловой акцент и характерная типографика |

После выбора развивается одно направление. При узкой правке существующего продукта скилл сохраняет его бренд и компоненты, не навязывая переработку всего интерфейса.

Направление не закрепляет конкретный цвет или шрифт. Акцент подбирается под продукт с проверкой контраста. Все компоненты, включая открытые выпадающие списки, формы и диалоги, должны соответствовать общей системе.

## Возможности

- Правила информационной иерархии, отступов, размеров текста, адаптивности и состояний интерфейса.
- Осмысленное выравнивание текста, иконок и содержимого контейнеров без безусловного центрирования.
- Практические требования доступности на основе WCAG 2.2: контраст, клавиатура, фокус, подписи полей и ошибки.
- Выбор шрифтов **по семейству**, с рекомендациями по направлениям и назначением внутренних ветвей по роли.
- Выбор одного согласованного набора иконок: **Lucide** или **Reicon**.
- CSS-токены светлой и тёмной тем и пресеты шрифтов.

Значения отступов и размеров — стартовые настройки, а не универсальные нормативы. Наличие скилла само по себе не подтверждает доступность готового продукта: реализацию нужно проверять.

## Шрифты

Каталог включает **Inter, Roboto, Geist, IBM Plex, Manrope, Segoe UI и Medeo**.

В выборе дизайна одна семья представлена одним пунктом. Например, Medeo — один вариант, а Sans, Serif, Mono и Pixel используются внутри него по назначению. Все ветви одновременно подключать не требуется. Поддержка русского проверяется для конкретной ветви и версии; её нельзя автоматически переносить на всё семейство.

Шрифты и иконки **не хранятся в репозитории**. Скилл содержит официальные ссылки и инструкции подключения через CDN, пакеты или системный стек. Зависимости автоматически не устанавливаются.

## Установка

1. Скачайте или клонируйте репозиторий.
2. Скопируйте папку **`skill-design` целиком** в каталог пользовательских скиллов Codex: `$CODEX_HOME/skills/` (обычно `~/.codex/skills/`).
3. В новой сессии вызовите скилл как **`$skill-design`**.

Итоговое расположение основного файла:

```text
~/.codex/skills/skill-design/SKILL.md
```

Для установки из этого репозитория выбирайте путь **`skill-design`**, а не корень репозитория.

## Примеры запросов

```text
Используй $skill-design. Подготовь три варианта интерфейса
управления проектами: точный, мягкий и выразительный.
Предоставь выбор семейства шрифта и набора иконок.
```

```text
Используй $skill-design. Доработай форму создания проекта
в текущем стиле. Проверь подписи, ошибки, клавиатуру и адаптивность.
```

Переключатели направления, шрифта и иконок нужны для сравнения дизайнов. В конечный продукт они добавляются только при необходимости для его пользователей.

## Состав

```text
skill-design/
├── SKILL.md                 Основные инструкции
├── references/
│   ├── ux-ui.md             UX/UI, выравнивание и доступность
│   ├── fonts.md             Семейства, рекомендации и подключения
│   └── icons.md             Наборы иконок и подключения
├── assets/
│   ├── tokens.css           Цвета, размеры, интервалы и скругления
│   └── font-presets.css     Семантические шрифтовые роли
└── scripts/
    └── check_design.py      Проверка контраста и покрытия шрифта
```

Браузерные демонстрации в состав репозитория не входят. CSS-файлы — заготовки для интеграции в систему проекта, а не автоматически применяемые глобальные стили.

## Вспомогательные проверки

Из папки `skill-design`:

```sh
python scripts/check_design.py contrast --foreground "#626773" --background "#ffffff"
python scripts/check_design.py font path/to/font.woff2
```

Расчёт контраста не требует сторонних пакетов. Для проверки файла шрифта нужны FontTools, а для WOFF2 — также Brotli. Скрипт не проверяет композицию, выравнивание или полное соответствие WCAG.

## Сторонние ресурсы и коммерческое использование

- **Inter, Roboto, Geist, IBM Plex, Manrope и Medeo:** указанные в каталоге версии распространяются по OFL; допускается коммерческое использование. При распространении файлов сохраняйте необходимые лицензионные уведомления.
- **Segoe UI:** используется установленный системный шрифт. Указание имени в CSS не даёт права копировать файлы из Windows на сервер или распространять их с продуктом.
- **Lucide:** соблюдайте ISC и уведомления исходных наборов.
- **Reicon:** соблюдайте MIT и условия исходных наборов, включая атрибуцию там, где она требуется.

Ссылки на официальные источники и условия приведены в [каталоге шрифтов](skill-design/references/fonts.md) и [каталоге иконок](skill-design/references/icons.md). Перед подключением проверяйте выбранную версию. Условия сторонних ресурсов не являются лицензией на код вашего продукта и не заменяют отдельную лицензию самого репозитория.
