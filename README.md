# Skill Design

Личная дизайн-система и скилл для проектирования веб-приложений, SaaS, дашбордов и продуктовых лендингов. Содержит правила UX/UI, типографику RU/EN, подключения иконок и переиспользуемые CSS-пресеты.

## Начало работы

Для нового дизайна сначала выбирается режим:

| Режим | Результат |
| --- | --- |
| **Задать оформление** | Работа по конкретным параметрам; недостающие параметры уточняются |
| **Интерактивное сравнение** | Рабочий демонстрационный макет с переключением оформления |
| **Подобрать автоматически** | Подбор по назначению проекта, аудитории, существующему интерфейсу и требованиям бренда |

Если режим или параметры уже заданы, повторный опрос не нужен. При узкой правке сохраняются согласованный дизайн и границы задачи.

## Стилистики

Порядок во всех вопросах, переключателях и сравнениях фиксирован:

1. **Мягкая** — плавная геометрия, свободная группировка и лёгкая глубина.
2. **Точная** — сдержанная геометрия, ясные выравнивания и компактный рабочий ритм.
3. **Выразительная** — сильная иерархия и осмысленный визуальный акцент.

Это не универсальные макеты: композиция определяется содержимым и задачей продукта. При смене стилистики обновляется вся система компонентов, включая навигацию, кнопки, поля, открытые меню, карточки и диалоги.

## Настройки интерактивного сравнения

- **Шрифтовая семья:** Inter, Roboto, Geist, IBM Plex, Manrope, Segoe UI или Medeo. Один пункт на семью, рекомендации стилистик — в скобках. Внутренние ветви применяются по роли и языку.
- **Иконки:** Lucide или Reicon; один согласованный набор.
- **Акценты:** синий, зелёный, фиолетовый, бирюзовый, розовый, красный и графитовый, а также собственный цвет. Дополнительные цвета имеют определённые роли.
- **Темы:** светлая, тёмная и серая.
- **Стекло:** отдельный необязательный эффект, выключенный по умолчанию; регулируется прозрачность фона, а не текста. Предусмотрен непрозрачный вариант для доступности.
- **Загрузка:** просмотр анимированных skeleton-заглушек и демонстрация перехода к данным; уменьшение движения отключает волну.

Панель оформления размещается отдельно от рабочего холста и не перекрывает продукт. Её переключатели не добавляются в конечный интерфейс без продуктовой необходимости.

## Основные правила

Осмысленная композиция без случайного декора, согласованные размеры и отступы, выравнивание по роли содержимого, различимые слои и состояния. Градиенты, крупные заголовки и скругления допустимы при обоснованном применении.

Проверка охватывает фактический контраст текста и иконок, клавиатуру и фокус, открытые списки, выбранные состояния, адаптивность, масштабирование и прокрутку. Панели раскрываются по содержимому; внутренний скролл появляется только при нехватке места и остаётся внутри рамки без лишних вложенных отступов.

Поведение продукта включает понятные подписи действий, сохранность работы, возврат к контексту, постепенное раскрытие сложности и прозрачные условия. Движение должно быть уместным, отзывчивым и прерываемым там, где им управляет пользователь.

При каждой правке агент определяет применимые правила, вносит изменение, проверяет затронутый результат и устраняет вызванные нарушения. Сам скилл не является фоновым валидатором и не гарантирует доступность продукта без проверки реализации.

## Установка

Скопируйте папку **skill-design целиком** в каталог скиллов Codex: `$CODEX_HOME/skills/` (обычно `~/.codex/skills/`). Начните новую сессию и вызовите `$skill-design`.

Основной файл должен находиться по пути:

```text
~/.codex/skills/skill-design/SKILL.md
```

При установке из этого репозитория выбирайте путь `skill-design`, а не корень репозитория.

## Примеры запросов

```text
Используй $skill-design. Подготовь интерактивное сравнение
интерфейса управления проектами с переключением стилистик,
семейств шрифтов, иконок, тем и акцентных цветов.
```

```text
Используй $skill-design. Подбери оформление автоматически.
Изучи проект и сохрани обязательные требования бренда.
```

```text
Используй $skill-design. Доработай форму в текущем стиле.
Проверь ошибки, клавиатуру, контраст и адаптивность.
```

## Состав

```text
skill-design/
├── SKILL.md
├── references/
│   ├── design-setup.md       Режимы, стилистики, бренд, темы и палитры
│   ├── ux-ui.md              UX/UI, взаимодействие, доступность и ревью
│   ├── fonts.md              Шрифтовые семьи и подключения
│   ├── icons.md              Иконки и подключения
│   └── glass.md              Необязательный эффект стекла
├── assets/
│   ├── tokens.css           Семантические токены трёх тем
│   ├── appearance-presets.css Стилистики и акцентные палитры
│   ├── font-presets.css     Шрифтовые роли
│   ├── skeleton.css         Анимированные заглушки загрузки
│   ├── glass.css            Опциональный материал и контролы
│   └── glass-controls.js    Подключаемый тумблер и ползунок
└── scripts/
    └── check_design.py      Контраст и покрытие файла шрифта
```

Браузерные демонстрации в репозиторий не входят. Ресурсы в assets подключаются явно; CSS-пресеты задают роли, которые должны использовать компоненты проекта. Они не заменяют существующий интерфейс автоматически.

Шрифтовые файлы, библиотечные архивы и паки SVG не хранятся в скилле. Подключения выполняются в целевом проекте через официальные пакеты, CDN или системный стек.

## Проверки

Из папки skill-design:

```sh
python scripts/check_design.py contrast --foreground "#545c69" --background "#ffffff"
python scripts/check_design.py font path/to/font.woff2
```

Расчёт контраста не требует сторонних пакетов. Для проверки файла шрифта нужны FontTools и, для WOFF2, Brotli. Скрипт не проверяет композицию, все состояния интерфейса или полное соответствие WCAG.

Официальные ссылки в справочниках нужны для подключения ресурсов, проверки API, стандартов и условий использования.

- **Inter, Roboto, Geist, IBM Plex, Manrope, Medeo:** указанные версии доступны по OFL; при распространении файлов сохраняйте необходимые уведомления.
- **Segoe UI:** системное использование; указание имени в CSS не даёт права копировать файлы Windows на сервер или распространять их с продуктом.
- **Lucide:** ISC и уведомления исходных наборов.
- **Reicon:** MIT и условия исходных наборов, включая атрибуцию там, где она требуется.

Перед подключением проверяйте условия конкретной версии. Условия сторонних ресурсов не становятся лицензией на код вашего продукта и не заменяют отдельную лицензию самого репозитория.
