# Skill Design — подготовленный выпуск

- Пять направлений: Мягкая, Точная, Выразительная, Фокусная, Компактная.
- Строгий контраст для CI и необязательный браузерный аудит с axe-core.
- Режим аудита и интеграция React/Tailwind/shadcn.
- Проектная и пользовательская установка для Codex/Claude Code.
- Генератор независимого Next.js-примера.
- MIT для собственных ресурсов; лицензии сторонних ресурсов остаются отдельными.

Браузеры и библиотеки не входят в архив скилла. Реальное независимое сравнение качества агента со скиллом и без него не заявляется: методика описана отдельно, контрольные примеры инструментов не заменяют такой эксперимент.
